# Hotel Management System

A web-based system to streamline and automate key hotel operations — room reservations, guest check-in/check-out, billing, and staff management — improving overall efficiency and guest experience.

## Features

- **Room Reservations** — Book rooms and manage availability in real time
- **Guest Check-in / Check-out** — Track guest stays from arrival to departure
- **Billing** — Generate and manage guest billing
- **Staff Management** — Manage staff schedules and resources
- **Inventory Tracking** — Monitor hotel supplies and resources
- **Reporting** — Generate reports to support better decision-making

## Tech Stack

- **Backend:** Python (Flask)
- **Frontend:** HTML, CSS, JavaScript
- **Database:** MySQL

## How It Works

The system integrates core hotel services into a single platform, enabling real-time tracking of room availability, customer preferences, inventory, and billing. This reduces manual errors, optimizes staff resource management, and improves the overall guest experience.

## Getting Started

### Prerequisites

- Python 3.x
- MySQL Server
- pip (Python package manager)

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/ankur8519/<repo-name>.git
   cd <repo-name>
   ```

2. Install dependencies
   ```bash
   pip install -r requirements.txt
   ```

3. Set up the MySQL database
   - Create a new database in MySQL
   - Update the database connection details in the project's configuration file

4. Run the application
   ```bash
   python app.py
   ```

5. Open your browser and navigate to `http://localhost:5000`
